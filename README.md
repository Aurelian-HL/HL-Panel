# HL-panel

[![正式版本](https://img.shields.io/github/v/release/Aurelian-HL/HL-Panel)](https://github.com/Aurelian-HL/HL-Panel/releases/latest)
[![发布检查](https://github.com/Aurelian-HL/HL-Panel/actions/workflows/release.yml/badge.svg)](https://github.com/Aurelian-HL/HL-Panel/actions/workflows/release.yml)
[![技术栈](https://img.shields.io/badge/Go%20%2B%20Vue%203-PostgreSQL-334155)](#功能与支持范围)

**面向 VPS 的网络控制与转发面板。** 集中管理用户、设备组、转发规则、节点探针和客户端订阅，支持保数据更新与加密迁移备份。

管理端使用 Go、Vue 3 和 PostgreSQL；节点端由 HL Agent 管理 Xray / GOST，探针随 Agent 一起安装。

[快速开始](#快速开始) · [面板与节点更新](#面板与节点更新) · [证书与域名](#证书与域名) · [使用指南](docs/user-guide.md) · [常见问题](#常见问题) · [发布说明](https://github.com/Aurelian-HL/HL-Panel/releases)

## 先分清：你正在操作哪台服务器？

| 服务器角色 | 安装了什么 | 在这台机器上执行什么 |
| --- | --- | --- |
| **面板服务器** | 网页管理端、控制 API、PostgreSQL | 全新安装用 `install.sh`；已有面板更新用 **`update.sh`** |
| **节点服务器** | HL Agent、主机探针、Xray、GOST | 安装或换组用面板生成的 `install-node.sh` 完整命令；已有节点更新用 **`update-node.sh`** |

> [!IMPORTANT]
> **SSH 登录哪台机器，命令就作用于哪台机器。** 节点更新命令要在目标节点服务器执行，不是在面板服务器执行。面板网页中的“版本 → 保数据更新”只更新面板，**不会自动升级节点**。完整更新顺序是：**面板 → 一台节点并验收 → 其余节点逐台更新**。

## 快速开始

首次使用：**安装面板 → 登录改密 → 创建设备组 → 安装节点 → 创建规则 → 客户端验证**。

### 1. 准备面板服务器

| 项目 | 要求 |
| --- | --- |
| 系统 | Debian 12 / Ubuntu 22.04 及更新版本，使用 apt 和 systemd |
| 架构 | x86_64 / amd64；当前一键安装包不提供 ARM 版本 |
| 权限 | 通过 SSH 登录面板服务器，以 root 执行安装 |
| 网络 | 能访问 GitHub API、Release 和脚本下载地址 |
| 入站端口 | TCP 80、443；使用 IP HTTPS 入口时还需 TCP 8443（可改） |
| 域名 | 可选；推荐绑定自己的域名以使用受信任的 HTTPS 证书 |

请先在云平台安全组和系统防火墙放行相应端口，安装器不会自动修改这些规则。建议使用全新 VPS；已有实例请走[更新流程](#面板与节点更新)。

有域名时，将域名的 A 记录全部指向面板服务器公网 IPv4。当前自动签发流程要求没有 AAAA 记录，并使用 DNS 直连模式；有 CDN 代理时先关闭代理。没有域名也可以先安装，通过 IP 入口访问。

### 2. 安装面板：仅在全新面板服务器执行

```sh
curl -fsSL https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/install.sh | bash
```

若提示没有 `curl`，先执行 `apt-get update && apt-get install -y curl`，再运行上面的命令。

安装入口会解析最新正式 Release，使用同一标签的安装器和程序包，校验 SHA256。终端会依次询问：

| 终端提示 | 如何填写 | 直接回车 |
| --- | --- | --- |
| `设置面板域名 [回车使用 IP 访问]：` | 如 `panel.example.com`，不带协议、端口或路径 | 使用 IP 入口 |
| `设置 HL-panel 管理员账号 [admin]：` | 填自己的管理员账号 | 使用 `admin` |
| `设置 HL-panel 管理员密码 [回车使用 123456]：` | 建议自定义 8～256 个字符的密码 | 使用 `123456`，首次登录强制改密 |
| `再次输入管理员密码：` | 再次填写相同的自定义密码 | 仅自定义密码时出现 |

密码输入时不会显示字符或星号，安装器也不会打印自定义密码。接下来自动下载程序、安装依赖、创建数据库、启动服务并尝试申请证书，无需选择额外菜单。保持终端连接，直到显示 **HL-panel 安装完成**。

需要调整参数时，例如选择空闲 API 与 IP HTTPS 端口：

```sh
curl -fsSL https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/install.sh | bash -s -- --domain panel.example.com --api-port 8081 --ip-https-port 9443
```

将示例域名替换为自己的域名，并放行所选 IP HTTPS 端口。还支持 `--admin-username`、`--public-ip`、`--email` 和 `--version`；不要把管理员密码写进命令。参数与 Nginx 适配说明见[安装与运维手册](deploy/README.md)。

### 3. 登录面板

- **域名证书申请成功**：打开安装结果显示的 `https://你的域名/`。
- **没有域名或签发失败**：使用 `https://你的公网IPv4:8443/`，自定义过端口则使用实际端口。IP 入口使用自签名证书，浏览器会提示证书警告，请核对服务器身份；正式使用推荐域名证书。
- **默认管理员**：账号 **`admin`**，密码 **`123456`**；自定义过则使用安装时设置的账号密码。默认密码首次登录后必须修改，改密后重新登录。

VPS 的 SSH 密码与面板管理员密码是两套独立凭据。面板保数据更新不会重置已修改的管理员密码。

### 4. 安装节点：仅在目标节点服务器执行

1. 登录面板，创建入口或出口设备组。
2. 打开目标组的 **对接 → 海外节点安装**，生成注册令牌，复制页面给出的**完整安装命令**。
3. SSH 登录要加入该组的**节点服务器**，以 root 粘贴整条命令。不要在面板服务器执行。
4. 命令会安装 Agent、主机探针、Xray 和 GOST，完成注册入组并设置开机自启，无需分别安装引擎。
5. 等待终端确认注册和启动完成，再回到面板查看组成员、探针与版本。

**不要只复制令牌，也不要单独运行不带参数的 `install-node.sh`。** 完整命令包含面板 HTTPS 地址和一次性令牌；一台节点使用一条新命令。默认令牌有效期为 15 分钟，可在页面选择更长有效期。不要公开命令中的令牌。

节点需为 Linux amd64 / systemd 环境，能访问面板 HTTPS 和 GitHub；在线安装会补充 Python 3 与 CA 证书。默认安装版本跟随所属面板的正式版本，引擎版本以该 Release 包内清单为准，不单独追踪上游 latest。

安装节点不会自动创建业务规则。按需放行节点实际使用的业务端口（默认监听端口不低于 1024），创建并下发规则，等待节点应用成功，再用真实客户端验证。**心跳在线不代表转发已连通。**

已有节点重装或换组：在**目标组生成新命令**，到原节点服务器执行。此流程保留节点身份及历史流量，以最近一次有效注册的组为准，切换会短暂中断连接。常规更新请使用下一节的保身份更新，操作细节见[节点使用指南](docs/user-guide.md#节点安装与维护)。

## 面板与节点更新

> [!WARNING]
> **以下是两个独立操作，不要在同一台机器上顺手执行两条命令。** 先核对当前 SSH 连接的服务器角色；面板用 `update.sh`，节点用 `update-node.sh`。更新前查看[发布说明](https://github.com/Aurelian-HL/HL-Panel/releases)，安排维护窗口并保留备份。

### 第一步：更新面板服务器

**执行位置：已安装 HL-panel 网页管理端的面板服务器，root 终端。**

```sh
curl -fsSL https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/update.sh | bash
```

面板更新保留账号、密码、用户、规则、设备组、节点记录、订阅、数据库、域名和证书。它会校验发布包、备份配置与数据库、短暂停止面板、执行迁移、启动并核对运行版本。节点转发进程不会因此被远程升级，但面板控制与订阅下载会有短暂中断。

也可以使用网页：**首页 → HL-Panel 运行状态 → 版本 → 刷新版本列表 → 选择正式版本 → 输入当前管理员密码 → 确认保数据更新**。旧安装未提供网页更新服务时，先执行上面的终端命令。

当前自动更新支持标准安装器创建的本机 PostgreSQL 实例。自定义或远程数据库请先阅读[更新与回滚指南](docs/upgrade-guide.md)。

### 第二步：更新每一台节点服务器

**执行位置：要更新的那一台节点服务器，root 终端。不是面板服务器。**

```sh
curl -fsSL https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/update-node.sh | bash
```

节点更新默认读取所属面板的当前正式版本，更新本机 Agent、探针及随包分发的 Xray / GOST，**保留节点身份、注册凭据、配置、流量账本和最后有效规则，不需要新令牌，也不会重新换组**。

更新切换会重启本节点服务，已有连接需要重连。先更新一台，确认节点重新在线、版本正确、配置已应用、采样正常且真实转发可用，再依次更新其他节点；不要同时更新整组。

### 更新完成如何确认

| 核对位置 | 核对内容 |
| --- | --- |
| 面板首页的版本弹窗 | 当前运行版本是否为目标正式版本 |
| 设备探针 / 设备组 | 节点是否恢复在线，Agent 版本及采样是否正常 |
| 转发规则 | 节点配置是否应用成功，规则是否可用 |
| 真实客户端 | 订阅能否下载、刷新，线路能否实际传输数据 |

更新器会显示备份目录和回滚命令。失败时保留日志与备份，不要通过删除配置或重装来处理。**误在面板机执行节点更新、指定版本、离线排查、回滚方法**见[面板与节点更新指南](docs/upgrade-guide.md)。

正式版本以 [GitHub Releases](https://github.com/Aurelian-HL/HL-Panel/releases) 为准；main 提交或 README 修改不等于发布了新版本，也不会自动更新已安装的机器。面板落后 1～2 个正式版本可暂缓提醒，落后 3 个及以上持续提示；GitHub 查询失败显示未核实，不会误报已是最新。

## 功能与支持范围

| 模块 | 主要能力 |
| --- | --- |
| 用户与授权 | 用户、用户组、有效期、流量额度、设备组授权 |
| 设备组与节点 | 入口 / 出口组、成员与权重、一键注册、重装换组、退役记录及未入组节点清理 |
| 转发规则 | 创建、编辑、启停、端口分配、分页筛选、直连与出口组选择、配置下发及应用回执 |
| 流量额度 | 单规则限额、超额自动暂停、可选按 UTC 自然月清零；1024 MB = 1 GB，1024 GB = 1 TB |
| 协议与引擎 | Xray / GOST 受管运行，TCP / UDP 转发，VLESS Reality + Vision TCP，直连或 SOCKS5 落地 |
| 订阅管理 | 规则一键生成订阅、手工多线路订阅、TXT / YAML、ZIP 导入包、在线订阅及离线节点二维码 |
| 系统与探针 | 面板主机系统状态、节点主机指标、运行与操作日志；节点速度、连接及流量汇总 |
| 运维 | 正式版本检查、网页 / 终端保数据更新、节点保身份更新、加密导出导入、同域名自动迁移 |

设备组提供一个稳定接入地址，按新连接调度；后端故障后客户端需要重连。多 A 记录直接指向节点时，客户端可能自行选中任一地址，面板调度不会自动摘除 DNS 中的失效地址。

原生 TCP / UDP 转发不是代理订阅协议；支持的客户端、订阅格式、流量口径与生效边界见[使用指南](docs/user-guide.md#转发规则分页与订阅管理)。本项目不包含商城、订单、支付、钱包或推广返佣模块。

## 证书与域名

安装时填写域名且 DNS、TCP 80、CAA 与签发限制满足要求时，安装器会通过 Certbot / Let's Encrypt 自动申请域名证书并启用 HTTPS。系统提供 `certbot.timer` 时会启用续期定时器；没有该定时器时需按发行版配置续期任务。

**首次签发失败后，DNS 修好并不会自动触发首次申请。** 在**面板服务器**的 root 终端执行：

```sh
hl-panel-enable-domain-tls
```

安装时没填域名的，先按[后续绑定域名](deploy/README.md#后续绑定域名)配置。证书链、自动续期、Reality 目标以及设备时间问题见[证书排障](docs/user-guide.md#证书与-reality)。不要用关闭 TLS 校验处理证书错误。

## 备份与迁移

打开 **首页 → HL-Panel 运行状态 → 迁移备份**：

- **导出 / 导入**：生成加密 `.hlbackup`，在另一台已安装的面板校验并预览后恢复。包含管理员、用户、规则、设备组、节点身份、订阅、限额和流量账本；目标版本不得低于备份版本。导入后使用备份中的管理员账号密码。
- **自动迁移**：适用于同域名迁移到全新服务器。在当前面板填写新机 SSH 信息并核对指纹，准备新机、正式切换、手动修改 DNS，解析就绪后自动处理证书并启用新面板。不会自动删除旧机。

备份密码与备份文件分别保管。迁移不等于复制整台操作系统，证书、环境与节点连接地址仍需按流程处理。执行前阅读[迁移备份与恢复手册](deploy/backup-and-restore.md)，其中包含切换顺序、中断续接和回滚边界。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 更新了面板，节点版本怎么没变？ | 面板与节点独立更新。先确认面板版本，再 SSH 登录每台节点执行 `update-node.sh`。 |
| 在面板机运行了节点更新命令 | 不要删除文件或重新安装；看[误执行处理](docs/upgrade-guide.md#误执行了另一种更新命令)。没有受管节点配置时，更新器会拒绝继续。 |
| 提示已有实例或数据库 | 保留现有数据，使用 `update.sh`，不要用 `install.sh` 覆盖。 |
| 节点在线但“待激活”或无法下载订阅包 | 查看规则的应用回执、引擎启动结果、额度及节点状态；在线只说明心跳正常。见[节点维护](docs/node-maintenance.md)。 |
| 探针未采集 / 采样过期 | 核对节点版本、最近心跳、面板 HTTPS 与系统时间；CPU / 速率从第二次采样开始显示。详见[使用指南](docs/user-guide.md)。 |
| 节点连不上面板 HTTPS | 检查 DNS、证书链、有效期、系统自动时间和网络；自签名入口需配置受信任 CA，不能跳过校验。 |
| 订阅链接导入失败，拖入 YAML 却可用 | 文件是下载时的快照，在线订阅还依赖面板 HTTPS 可达；按[订阅导入排障](docs/user-guide.md#一键生成规则订阅和导入包)检查。 |
| 清理未入组或退役节点 | 在设备探针清理未入组机器，或在设备组删除退役记录；仍被有效组成员关系或稳定端点引用的节点不能直接清理。详见[节点清理](docs/user-guide.md#清理未入组离线和退役节点)。 |

## 反馈与贡献

欢迎提交 [Issue](https://github.com/Aurelian-HL/HL-Panel/issues) 或 [Pull Request](https://github.com/Aurelian-HL/HL-Panel/pulls)。报告问题时请提供：面板和节点版本、服务器系统与架构、操作步骤、预期与实际结果，以及带时间和时区的脱敏错误日志。安装或更新问题请注明**在哪种服务器执行了哪个脚本**。

请勿公开 SSH 密码、注册令牌、完整订阅地址、用户 UUID、数据库连接串、备份包或私钥。修改安装 / 更新流程时，请同步维护本文及对应指南；行为变更需经过发布检查并生成新的正式 Release，不覆盖已发布的标签和安装包。

感谢 [Xray-core](https://github.com/XTLS/Xray-core) 与 [GOST](https://github.com/go-gost/gost) 等上游项目。随包引擎的版本、来源、摘要与许可证以正式 Release 包内 `licenses/` 清单为准。
