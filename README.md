# HL-Panel releases

This public repository contains installation and update scripts and official binary releases.
Application source and build records are maintained in a separate private repository.
The installation and update addresses remain compatible with previous releases.

## Install panel

```bash
curl -fsSL https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/install.sh | bash
```

Use the node enrollment command generated by your panel to install a node.
Existing installations can continue to use the panel's system update function.
Download archives and SHA-256 checksums from Releases; source archives contain installers only.
No source repository credential or build secret is needed on a server.

The bundled Xray and GOST engines retain their respective upstream licenses.
