# HL-panel

HL-panel 是面向 VPS 的网络控制与转发面板，使用 Go、Vue 3 和 PostgreSQL。提供用户与授权、入口和出口设备组、转发规则和节点管理。节点通过一条带令牌的命令安装 HL Agent、自有主机探针、Xray 和 GOST。

首次使用的顺序：**安装面板 → 登录并修改默认密码 → 创建设备组 → 安装节点 → 创建并下发规则 → 用客户端测试**。安装节点不会自动创建业务规则或开通专线。

## 第一次安装：照着做即可

### 1. 准备一台 VPS

使用 Debian 12 或 Ubuntu 22.04 及更新版本，CPU 架构为 **x86_64 / amd64**，系统需要支持 systemd。通过 SSH 登录 VPS，再切换到 root。这里输入的是 **VPS 的 SSH 密码**，面板管理员密码在安装时单独设置。

在 VPS 供应商的安全组中允许 TCP **80、443、8443**，并检查系统防火墙。安装器不会替你修改防火墙或安全组。

有域名：添加一条 A 记录，把自己的域名（例如 `panel.example.com`）指向 VPS 公网 IPv4。当前自动证书流程要求没有 AAAA 记录；如果使用 CDN，请先关闭代理，使用直接解析。没有域名：也能安装，后面直接回车，先通过 IP 访问。

### 2. 复制命令，按回车

在 VPS 的 root 终端粘贴以下完整命令：

```sh
curl -fsSL https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/install.sh | bash
```

如果提示 `curl: command not found`，先执行 `apt-get update && apt-get install -y curl`，再重新粘贴安装命令。

命令会选定 GitHub 最新正式 Release，然后下载**同一标签**的安装器与程序包并校验 SHA256。它用于全新安装；已有实例请使用下方的更新命令。

### 3. 终端会依次询问什么

下面是终端实际出现的提示。填写后按回车；直接按回车表示采用表中的默认值。

| 终端提示 | 你要填写什么 | 直接回车的结果 |
| --- | --- | --- |
| `设置面板域名 [回车使用 IP 访问]：` | 自己的域名，如 `panel.example.com`；不要加 `https://`、端口或斜杠 | 使用 IP 入口 |
| `设置 HL-panel 管理员账号 [admin]：` | 自定义账号；可用字母、数字、点、下划线、@、连字符 | 账号为 `admin` |
| `设置 HL-panel 管理员密码 [回车使用 123456]：` | 建议填写自己的密码，8～256 个字符 | 密码为 `123456`，首登要求改密 |
| `再次输入管理员密码：` | 再输入同一个自定义密码 | 仅自定义密码时出现，必须一致 |

**输入密码时屏幕不会显示字符或星号，这是正常的。** 安装器不会打印自定义密码。密码不合法或两次不一致时会停止，按提示重新执行命令。

接下来会显示下载、安装依赖、创建数据库、启动服务和域名证书检查进度，无需再选择菜单。保持终端连接，直到看到 **HL-panel 安装完成**。末尾会显示实际安装版本、访问地址、管理员账号和密码说明。默认凭据会明确显示 **admin / 123456**；自定义密码只提示使用刚设置的密码。

### 4. 打开面板并登录

域名证书成功时，打开安装结果中的 `https://你的域名/`。没填域名、域名解析未生效或申请证书失败时，打开 `https://你的公网IPv4:8443/`；若改了 IP 端口，使用安装结果显示的端口。

IP 入口使用自签名证书，浏览器会提示证书警告。确认地址是自己的 VPS 后再访问；希望浏览器正常信任证书，请绑定域名并按下一节申请域名证书。

默认登录信息：**账号 `admin`，密码 `123456`**。安装时自定义过账号或密码，则使用自己设置的内容。默认密码首次登录会转到个人中心，先设置至少 8 个字符的新密码，再用新密码重新登录。改密前不能操作其他管理功能。以后重启和保数据更新都会保留新密码。

### 5. 常见安装问题

| 提示或现象 | 怎么处理 |
| --- | --- |
| 提示已有 HL-panel 文件、数据库或实例 | 不要删除数据重装，使用“保留数据更新”命令 |
| API 端口 8080 被占用 | 重新运行安装命令，在末尾加 `-s -- --api-port 8081`，选择空闲端口 |
| IP HTTPS 端口 8443 被占用 | 加 `-s -- --ip-https-port 9443`，并在安全组允许 TCP 9443 |
| 无法确认公网 IP | 加 `-s -- --public-ip 你的公网IPv4` |
| 旧版出现 `unknown directive "limit_req_zone"` | 撤销完成后重跑最新安装命令；新版会自动备份并将发行版 `nginx-light` 适配为 `nginx-core` |
| 登录失败 | 检查账号大小写，手动输入密码，避免浏览器填入旧密码；改密后使用新密码 |
| 网址打不开 | 使用末尾显示的完整地址；检查安全组、防火墙和服务状态，IP 入口记得带端口 |
| 首页 CPU、内存、负载或运行时间显示“未采集”，但磁盘正常 | 旧版 systemd 的 `ProcSubset=pid` 会隐藏主机指标文件。使用下方“保留数据更新”命令升级，更新器会添加受管服务配置并重启面板，无需重装或清空数据。CPU 从第二次采样开始显示；未配置交换分区时显示“未启用” |

#### Nginx 模块不足

面板登录限流需要 Nginx 的 `http_limit_req` 模块。Ubuntu 22.04 的 `nginx-light` 不包含该模块。新版安装器在未安装 Nginx 的 VPS 上直接安装 `nginx-core`；检测到已有发行版 `nginx-light` 模块不足时，会**备份现有 Nginx 配置、自动安装 nginx-core、保留原站点配置、验证模块和站点配置后继续安装面板**，无需手动换包。原 Nginx 正在运行时，会短暂重启以使用新程序；适配失败则自动恢复原软件包类型、配置和服务状态，终端显示备份位置。

如果旧版出现这个错误，先确认终端已完成“撤销本次新建的 HL-panel 资源”，然后重新执行上面的最新面板安装命令，重新填写域名、账号和密码即可。如果提示已有面板文件或数据库，请保留数据并使用更新命令，不要手动删除目录或数据库。自编译或第三方 Nginx 不会被发行版软件包强行覆盖；如果它缺少必要模块，会提示安装兼容版本。登录限流会继续保留。

例如，指定域名、账号和空闲端口（把示例域名换成自己的）：

```sh
curl -fsSL https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/install.sh | bash -s -- --domain panel.example.com --admin-username myadmin --api-port 8081 --ip-https-port 9443
```

可选参数：`--email admin@example.com` 设置证书通知邮箱，`--version vX.Y.Z` 安装指定正式版本。完整说明见 [安装与运维手册](deploy/README.md)。

使用 `--domain` 或 `--admin-username` 后，对应的域名或账号问题会跳过，密码仍在终端中隐藏输入。不要把自定义管理员密码写进安装命令。

## 证书会自动申请吗？

**填写域名且满足验证条件时，安装器会自动申请并启用面板域名证书。** 使用 Certbot 和 Let's Encrypt 的 HTTP-01 验证：

1. 安装时填写自己的域名。
2. 域名的 A 记录全部指向这台 VPS 的公网 IPv4，且没有 AAAA 记录。
3. 域名直接解析到 VPS，外部能访问 TCP 80 的验证路径；TCP 443 用于 HTTPS。
4. VPS 能访问证书服务，域名的 CAA 与 Let's Encrypt 的签发限制允许申请。

满足条件时自动申请正式证书，检查证书与私钥匹配，并启用域名 HTTPS。系统提供 `certbot.timer` 时，安装器会启用它定期续期；若系统没有这个定时器，会提示自行配置续期任务。续期钩子更新面板证书，Nginx 配置检查通过后重新加载。

不满足条件时会提示原因并保留 IP 入口，**不会把自签名证书当作正式证书**。DNS 后来生效不会自动触发第一次签发；修正解析后，在 root 终端执行：

```sh
hl-panel-enable-domain-tls
```

如果安装时没填域名，先按 [后续绑定域名步骤](deploy/README.md#后续绑定域名) 设置自己的域名，再执行上述命令。

### 申请失败如何处理

先确认域名 A 记录是当前 VPS 公网 IPv4，去掉 AAAA，关闭 CDN 代理，并允许 TCP 80 和 443。检查是否有其他 Nginx 站点截走验证请求；修改后重新执行 `hl-panel-enable-domain-tls`。CAA 必须允许 Let's Encrypt；遇到签发次数限制，需要按错误提示等待，反复重试不能解除限制。详细错误可在 `/var/log/letsencrypt/letsencrypt.log` 查看，反馈前请脱敏。

检查续期定时器与模拟续期：

```sh
systemctl status certbot.timer --no-pager
certbot renew --dry-run
```

若系统有这个定时器但没有启用，执行 `systemctl enable --now certbot.timer`。若提示定时器不存在，需要按发行版配置定时执行 `certbot renew --quiet`，不要将首次申请成功当作续期任务已生效。模拟续期也依赖域名解析和 TCP 80 可达。

这里自动管理的是**面板访问证书**。正式域名证书启用后，安装器会验证该域名支持 TLS 1.3、X25519 和可信证书，并配置为默认 Reality 目标。Reality 节点使用面板生成的密钥，不需要复制面板私钥或另行申请业务证书。

只使用 IP 入口、证书尚未签发或目标验证失败时，先处理上述 DNS / 证书问题，再运行 `hl-panel-enable-domain-tls`。也可选择自己控制的、支持 TLS 1.3 和 X25519 的 HTTPS 域名，执行：

```sh
hl-panel-configure-reality target.example.com
```

命令核验目标后备份配置，只重启 HL-panel API；失败恢复原配置。已有面板保数据升级后，可执行 `python3 /opt/hl-panel/current/deploy/configure-reality.py target.example.com`。所有业务节点必须能访问该目标；目标不可用时应处理目标或更换后更新规则。

## 节点机：一条命令安装、注册并启用转发引擎

面板安装在管理 VPS；入口节点和出口节点在各自的 VPS 上安装。不要把面板安装命令当作节点安装命令。

1. 登录面板，进入 **设备组**，新建或选择入口组 / 出口组，点击该组的 **对接 → 海外节点安装**。这是当前一键安装入口；“自动探测线路（安装器待发布）”的线路探测流程尚未发布。
2. 确认弹窗中的设备组，选择 **有效时间**（默认 15 分钟，也可选 30 分钟或 1 小时）。“关联已有哪吒节点”可保持 **暂不关联**，不影响 HL 自有探针安装。
3. 点击 **生成注册令牌**，再点击 **复制安装命令**。复制的是包含一次性令牌和当前面板 HTTPS 地址的完整命令；只复制“令牌”文本不能完成安装。关闭弹窗后无法再次查看令牌原文，请在到期前执行命令。
4. 通过 SSH 登录要加入的节点机，切换到 root，粘贴完整命令后按回车。无需再次输入令牌，也无需分别安装探针、Xray 或 GOST。
5. 终端依次显示读取面板版本、验证同版本安装包、安装引擎、自动注册和启用开机自启。注册最多等待 90 秒，短暂网络中断会自动重试，每 15 秒提示进度。看到服务已注册并启动后，返回面板，约 30 秒后刷新本组成员和探针。
6. 在面板创建并下发转发规则。Agent 按有效规则启动对应引擎；再用客户端确认实际流量。节点在线只代表心跳正常。

每台节点都需要能访问面板 HTTPS 地址和 GitHub 下载地址。节点的安全组与防火墙还需允许规则实际使用的监听端口；面板的 80 / 443 / 8443 开放要求不代替节点业务端口设置。

安装命令的形式如下，**请优先复制面板生成的完整命令**。手动使用时，把域名和占位令牌换成自己的：

```sh
(set +x; set -e; f=$(mktemp); trap 'rm -f -- "$f"' EXIT; curl -fSL --proto '=https' --proto-redir '=https' --retry 2 --connect-timeout 15 --max-time 60 https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/install-node.sh -o "$f"; bash "$f" --panel-url 'https://panel.example.com' --token '替换为面板生成的令牌')
```

支持 Linux amd64 / systemd；预装 curl，在线安装器会补充 python3 和 CA 证书。命令含一次性秘密，请勿公开分享，执行后清除对应命令历史。令牌只允许一台机器注册，注册成功后本机删除一次性令牌文件，后续重启使用权限受限的节点凭据，不再需要令牌。

### 清理离线节点

在**设备探针**或**节点清单**中，离线 HL 节点的操作栏会显示**删除**。点击后核对节点名称和 IP，再点击**确认删除**。

- 在线节点不能删除；确认时会再次检查最新心跳，刚恢复在线的节点会提示稍后重试。
- 清理后，节点从清单和探针中移除，并退出设备组；旧凭据不能继续上报。历史流量和操作日志保留。
- 此操作只清理面板记录，不会卸载或停止远程机器上的服务。需要重新接入时，在目标组生成新令牌，再执行一条命令安装；已有身份会恢复并以新组为准。
- 重新使用已经消费的旧令牌不能恢复已删除节点。

### 已有节点重新安装或切换设备组

支持直接重跑完整安装命令，**以最近一次有效注册的设备组为准**，无需卸载、删除凭据或手动退出旧组。面板需先更新到 v0.1.42 或更新版本。

1. 在面板打开目标设备组。例如从组1切到组2，就在**组2**点击 **对接 → 海外节点安装**。
2. 生成一个**新令牌**，复制完整安装命令，在原节点机以 root 执行。
3. 终端显示发现已有节点、备份现有程序、确认设备组注册、更新 Agent / 探针 / Xray / GOST，最后显示重装完成和备份位置。
4. 返回面板刷新：同一个节点进入组2，旧组成员记录撤下，原组规则监听停止，改为下发组2规则。切换时转发连接会短暂中断；节点身份、累计流量与历史记录保留。

同一命令重复执行可安全恢复，不会新增重复节点。响应丢失会自动重试；令牌过期、撤销或认证失败时，现有服务继续运行。已经被后续换组替代的旧令牌不能把节点切回旧组；要再换组，请在目标组生成新命令。安装器会备份原程序，程序更新失败会尝试恢复；设备组仍采用本次已确认的注册。不同面板之间迁移不在此流程范围内。

节点版本默认跟随面板当前运行的正式版本，安装脚本和程序包使用同一个标签。这样面板尚未更新时，新增节点也不会误装不兼容的新版本。可以添加 `--version vX.Y.Z` 明确固定版本；已有失败安装应继续使用最初安装版本。

安装包内置 **Xray v26.3.27** 和 **GOST v3.3.1-nightly.20260922**，在构建时从各自官方项目下载并校验固定 SHA256，随本项目正式 Release 一起发布，附带许可证。节点安装时不再单独追踪上游 latest。运行模式是 mixed，允许 Agent 自动管理这两个进程；没有有效规则时不会自行开通转发或专线。默认服务使用独立低权限账号，转发监听端口使用 **1024 及以上**，不会自动修改防火墙或其他转发服务。

HL 自有探针随 Agent 安装，显示 CPU、主机内存、根磁盘、网络流量 / 速率、运行时间和连接数；CPU 与速率从第二次采样开始显示。无需部署哪吒，原有哪吒关联可以继续使用。主机公网 IP 优先读取节点网卡，缺失时使用心跳连接来源 IP 或安装时保存的注册 IP；私网地址不会当作公网地址展示。面板自动通过 HTTPS 向 ipwho.is 查询该公网 IP 的国家代码，只提交 IP，不发送账号、令牌或配置。首次查看后会异步补全属地，成功结果缓存 24 小时，失败 5 分钟后自动重试，不影响心跳与转发；旧节点只需更新面板，无需重装。无法取得的指标仍显示未采集。主机 IP / 属地不代表转发线路出口。

### 节点安装失败怎么处理

| 提示或现象 | 处理方法 |
| --- | --- |
| curl 未安装 | `apt-get update && apt-get install -y curl`，再执行完整命令 |
| 连接中断或注册未确认 | 检查网络后重跑原命令；安装文件和私有恢复状态保留，不必重新安装引擎 |
| 令牌过期、失效或被其他机器使用 | 在原设备组重新生成完整命令；尚未注册的同版本安装会继续注册 |
| 已有注册节点 | 面板更新到 v0.1.42 或更新版本；在目标组生成新命令直接重装，保留身份及流量，自动退出旧组 |
| 无法下载 GitHub 安装包 | 按 [节点离线安装](deploy/README.md#节点离线安装) 上传同版本安装包和摘要；仍需连接面板 |
| HTTPS 证书不受信任 | 优先绑定域名并申请正式证书；使用 IP 自签名证书时，按手册提供受信任的 CA 文件，不关闭 TLS 校验 |
| 服务运行但面板没上线 | 检查面板 HTTPS 可达、令牌有效期、系统时间及下方服务日志 |
| 在线但转发不通 | 检查规则是否下发、引擎启动结果、监听端口、安全组和防火墙，再用真实客户端连接 |

```sh
systemctl status hl-panel-edge-agent --no-pager
journalctl -u hl-panel-edge-agent -n 50 --no-pager
```

节点无需申请面板证书，安装器会验证面板 HTTPS。节点安装会自动识别公网 IPv4 并用它加入设备组；识别失败或有多网卡时，在复制的命令末尾添加 `--node-address 节点公网IP`。域名也可使用，但必须能被其他节点解析并直连。系统主机名保持原样。

### 节点保留身份更新

先更新面板，再在每台节点以 root 执行：

```sh
curl -fsSL https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/update-node.sh | bash
```

默认更新到面板当前正式版本；可追加 `bash -s -- --version vX.Y.Z` 固定版本。更新器验证同标签安装包和完整文件摘要，备份后只切换 HL Agent、Xray 和 GOST，保留注册凭据、配置、流量账本和最后可用规则；不会重新消耗令牌。失败自动恢复旧程序，终端显示备份和手动回滚命令。完成后在面板核对版本、在线状态，并用真实客户端测试转发。

规则流量来自 Xray/GOST 的规则计数，与探针展示的整机网卡流量不同。入口组倍率由面板核验并用于计费；经过出口组时再乘出口组倍率。每笔记录保存当时的倍率，重复上报不会重复扣流量，后续修改倍率也不会改变旧记录。升级时应先更新面板，再更新节点，以便流量采样和计费修复一起生效。

如果面板已创建节点但注册响应丢失，同一机器保留私有恢复文件后可在首次注册后的 24 小时内重跑原命令，取回同一节点身份，不重复入组。仅持有令牌的其他机器无法恢复该身份。不要删除或公开私有状态文件；超过恢复窗口仍未成功时，请先在面板检查节点，再处理失效令牌。

转发规则列表仍会显示每条规则的已用流量，用于确认规则是否产生过业务流量；独立的“流量统计”页面和范围查询已移除。用户额度、限额执行和底层账本仍由服务端保留，以保证现有规则和授权流程正常工作。

## 转发规则分页与订阅管理

### 转发规则分页

转发规则较多时，页面底部会显示当前范围、总条数和页码。**每页**可选择 `10`、`20`、`50`、`100`、`200`、`500` 或 `1000` 条，并使用“上一页 / 下一页”切换。搜索规则名称、目标地址，或切换状态和设备组筛选后，页面会自动回到第一页；移动端会把分页控件排成易于点击的两行。分页只改变显示方式，不改变规则、批量操作或流量数据。

### 一键生成规则订阅和导入包

新增 **VLESS Reality** 转发规则后，在规则右侧点击链接图标（手机端为 **订阅包**）。面板会自动创建并发布该规则的订阅，在 **订阅管理 → 订阅地址** 中显示，同时下载 ZIP，无需再选客户、填写线路或发布草稿。重复点击会复用同一条订阅和固定地址。

1. 下载后先解压 `规则名-订阅导入包.zip`。六个文件都以规则名开头：`规则名-电脑Clash直接拖入使用.yaml`、`规则名-Clash订阅链接.txt`、`规则名-电脑手机通用v2rayN订阅链接.txt`、`规则名-小火箭订阅链接.txt`、`规则名-苹果小火箭订阅二维码.png`、`规则名-导入使用说明.txt`。中文文件名采用 UTF-8，文本带 UTF-8 编码标记，方便 Windows 识别。
2. Clash / Mihomo 可以导入 YAML 文件；需要持续同步，请打开对应的“订阅地址.txt”，复制地址，在客户端从 URL 导入。v2rayN / Shadowrocket 使用各自文件中的地址，Shadowrocket 也可以扫描二维码。
3. 客户端节点昵称使用当前规则名，规则改名后更新客户端订阅即可同步，订阅地址保持不变。YAML 包含完整代理节点与“规则名-选择”策略组。规则暂停、额度耗尽或节点尚未就绪时，不会下载没有节点的空 ZIP，页面会提示具体原因；恢复规则或调整额度并等待节点应用后，再点击下载。已有订阅在不可用期间停止下发线路，恢复后在客户端更新订阅。包内 YAML 是下载时的快照。
4. 自动订阅可在订阅管理中查看详情、下载导入包、更换地址、停用或恢复。停用后，点击规则按钮不会自动恢复订阅，需要先在订阅管理点击 **恢复**。

原生 TCP / UDP 转发规则不是代理客户端协议，因此不生成 VLESS / Clash 订阅。它们仍可使用下面的单规则流量额度。

### 单规则流量额度与自动暂停

创建或编辑规则时填写 **规则流量额度（GB）**，例如 `10` 表示累计额度为 10 GB，`0` 表示不限量。1 GB = 10 亿字节。列表会显示已用流量与额度，并自动刷新状态。

额度按该规则的累计计费流量计算：Xray / GOST 的上下行规则流量合计，再使用当时的设备组倍率；不使用整机网卡流量，不按月清零。已有规则设置额度时也包含历史累计用量，编辑、重装面板程序或重启不会清零。

达到额度后，面板显示 **流量额度已用完**，自动下发停止该规则的节点配置，同时停止向订阅提供该线路。点击 **调整流量额度**，提高到已用量以上或改为 `0`，保存并等待节点应用后恢复；如果规则已被手动暂停，仍需手动恢复。

限额依赖节点采样、上报与配置应用周期，可能有少量超量；节点与面板断开时无法即时执行暂停。请保持节点在线，在规则状态和节点应用结果中确认是否已生效。

### 手动创建多线路订阅

管理员打开左侧 **订阅管理 → 订阅地址**。没有客户时，先在 **用户管理** 创建客户。然后按照以下步骤操作：

1. 点击 **创建订阅**，填写名称并选择客户。每个订阅可添加 1–100 条线路，每条线路填写不同的名称。
2. **线路来源** 可以选择“粘贴 SOCKS5 / VLESS 链接”，也可以选择“本面板 VLESS 凭据”。手工链接支持 SOCKS5、VLESS TCP（Reality / TLS / 无 TLS），暂不支持 WS、gRPC 等传输；不完整或不支持的参数会提示错误。原生凭据只能引用当前管理员有权管理的线路账号；多位客户引用同一凭据时共享底层账号，订阅客户仅控制下发资格。
3. 点击 **保存草稿**。此时列表显示“未发布”，客户端还不能访问。打开 **详情** 检查线路，再点击 **发布更新**，列表变为“已发布”。
4. 在 **详情** 复制客户端对应的地址：v2rayN / Shadowrocket 使用 **TXT**，Clash / Mihomo 使用 **YAML**。在客户端选择“从 URL / 订阅地址导入”，粘贴地址并更新订阅；也可点击 **TXT 二维码 / YAML 二维码** 扫码导入。
5. **导入包** 会下载 ZIP，包含 YAML 配置、TXT 订阅地址、Shadowrocket 二维码和使用说明。包内 YAML 是下载时的快照；需要持续同步请使用固定订阅地址。
6. 日后点击 **编辑** 调整线路，保存草稿后仍使用上次发布内容；点击 **发布更新** 才会下发新内容，地址保持不变。客户端还需刷新订阅，已建立的连接不会自动迁移。
7. **更换订阅地址** 会使旧地址立即失效，需要客户重新导入；**停用** 会停止订阅下发，可点击 **恢复** 重新启用。客户停用、到期或额度耗尽时同样停止下发。

订阅地址包含访问凭据，请勿公开。停用订阅或更换地址不会自动删除客户端已缓存的节点，也不会撤销底层线路账号；要禁止线路连接，请同时停用客户或撤销对应 VLESS 凭据。手工链接需要自行维护其账号与可用性。面板不代替用户检查手工线路的真实连通性。

### 本面板 VLESS 凭据

在 **订阅管理 → VLESS 凭据** 中，为运行中的 VLESS Reality + Vision TCP 规则签发凭据。规则需已部署，Reality 参数完整，并有绑定的 VLESS 稳定端点和健康节点。出站可以是直连或已配置的 SOCKS5 落地。

创建时选择规则和服务端点，随后可复制单条 URI 或在多线路订阅中引用该凭据。一组设备只产生一条稳定 URI，不会把组内每台节点展开成客户线路。**轮换**后，引用它的订阅会跟随当前凭据与就绪状态；配置尚未生效或节点不健康时暂不下发该线路。**撤销**会停用线路账号并清理对应节点凭据，撤销不可恢复，与订阅地址的“停用 / 恢复”不同。

客户侧认证接口 `GET /api/v1/customer/subscriptions` 仅返回当前客户的 VLESS 凭据与就绪 URI。管理员列表不包含 UUID、订阅令牌或线路密码；秘密仅在授权详情和订阅导入流程中显示。

## 迁移备份：换一台面板机器

从 v0.1.47 起，首页 **HL-Panel 运行状态** 中提供 **迁移备份**。支持导出一个加密 `.hlbackup` 包，再导入另一台已安装的面板，保留管理员、用户、规则、设备组、节点身份、订阅、限额、流量账本、设置和最近日志。

1. **旧面板导出**：点击 **迁移备份 → 导出备份**，输入管理员密码，设置并确认备份密码（至少 10 个字符），下载文件。
2. **新机安装**：执行本文的一键安装命令，完成登录改密，新面板版本不得低于备份版本。
3. **新面板导入**：点击 **导入恢复**，选择文件，填写当前新面板管理员密码和备份密码，点击 **校验并预览**。核对数量后勾选覆盖确认，点击 **确认导入并恢复**。
4. **重新登录**：成功后使用旧面板备份中的管理员账号密码；旧会话失效。系统会保留导入前恢复包，错误导入事务不会覆盖原数据。
5. **切换节点**：同域名迁移切换解析并处理新机证书；换域名或 IP 时逐台执行节点地址切换工具，无需重新注册。最后验证探针、配置世代、实际转发和订阅。

这是面板业务迁移，系统环境、端口、数据库连接和 HTTPS 证书由新机器配置；可选外部集成凭据需另行设置。备份文件和密码请分别安全保管。完整命令、证书处理、节点换地址与回滚方法见 [迁移备份操作手册](deploy/backup-and-restore.md)。

## 版本检查与保留数据更新

首页 **HL-Panel 运行状态 → 日志** 会打开日志弹窗。点击刷新读取最新记录，可选择最近 20～2000 条，搜索文字，并按信息、警告、错误筛选；右侧下载按钮保存当前筛选结果为 UTF-8 文本。日志来自本面板的运行和管理员操作请求，最多保留 2000 条及 2 MiB；标准安装会保存至受管日志文件，重启后继续保留。这不是节点引擎的访问日志，也不是整台 VPS 的系统日志。秘密和请求正文不会包含在日志中。升级前的旧运行日志不会自动导入。

首页 **HL-Panel 运行状态 → 版本** 会打开 GitHub 正式版本列表，按新到旧排列并标记当前版本。选择更新版本后，点击 **复制更新命令**，在面板机的 root 终端粘贴执行；完成后刷新网页核对版本号。旧版本可查看，自动更新不支持降级；需要回滚时使用更新终端提供的备份和回滚命令。列表最多读取最近 100 个正式发布，刷新按钮使用服务器的查询缓存。

面板登录后会自动向 GitHub 核对正式 Release，约每 15 分钟刷新；可以点击版本入口查看结果。版本以已发布的正式 Release 为准，main 分支的一次提交不算一个新安装版本，草稿和预发布不计入版本差。

| 落后正式版本数 | 面板行为 |
| --- | --- |
| 0 | 显示已同步 |
| 1～2 | 显示更新提醒，可点“下次更新”，同一个新版本暂缓 24 小时 |
| 3 个及以上 | 持续显示提醒，提供前往 GitHub 的入口和保数据更新说明，不能通过“下次更新”隐藏 |
| GitHub 暂时连接失败 | 明确显示尚未核实，可重试或打开仓库；不会误报已经是最新版本 |

检查不会自动重装或锁死业务。点击“保留数据更新”可复制更新命令，并查看更新步骤和发布说明。

在**已有 HL-panel 的 VPS** 上，以 root 执行：

```sh
curl -fsSL https://raw.githubusercontent.com/Aurelian-HL/HL-Panel/main/update.sh | bash
```

新版安装后也可直接执行 `hl-panel-update`。指定版本可用 `hl-panel-update --version vX.Y.Z`，仅检查可用 `hl-panel-update --check`。

更新会下载同标签的官方安装包、校验 SHA256 和文件摘要，先备份配置与 PostgreSQL 数据库，再短暂停止**本面板**，执行必要的迁移并切换程序。随后检查服务状态和实际运行版本。**账号、已修改密码、用户、规则、数据库、域名和证书全部保留，不重新创建数据库。** 当前自动更新支持标准安装器创建的本机 PostgreSQL 实例；自定义或远程数据库不会被自动处理。

升级失败时自动恢复升级前程序和数据库。终端显示备份目录与手动回滚命令，请保存它们。手动回滚会恢复到备份时刻，后续新数据应先另行备份；不要只切回旧程序而继续使用新格式数据库。更多说明见 [备份与恢复](deploy/backup-and-restore.md)。

**全新安装用 install.sh，已有实例更新用 update.sh，两个命令不要混用。** 建议使用上方仓库的一键更新命令，它会下载目标正式版本的更新器，完成该版本所需的保数据升级。 更新前请查看 [正式版本与发布说明](https://github.com/Aurelian-HL/HL-Panel/releases)，确认目标版本的变化与限制。README 更新和 main 分支提交不会自动升级已安装的面板，也不替代正式 Release。

## 功能与当前边界

| 模块 | 当前能力 | 开发中的能力 |
| --- | --- | --- |
| 用户与授权 | 用户、用户组、有效期、额度与设备组授权 | 完整计量与限额闭环 |
| 设备组 | 入口组、出口组、成员与权重、候选自动投影 | 动态网关配置与高可用 |
| 转发规则 | 创建、编辑、启停、端口分配、单规则累计流量额度与超额自动暂停、直连与出口组选择、配置下发与应用回执；TCP 直连与 VLESS Reality 跨机转发 | 更多路由组合与故障场景 |
| 节点 Agent | 带令牌的一键安装、自有主机探针、Xray/GOST 混合进程管理、配置校验、重启恢复与回滚 | mTLS 与更大规模的节点管理 |
| VLESS | TLS / Vision / Reality 配置编译、单一稳定 URI、凭据轮换与撤销、客户侧就绪状态投影 | 更大规模的节点密钥轮换与多协议订阅 |
| 订阅管理 | 规则一键生成并发布订阅、ZIP 导入包、多线路固定地址、TXT / YAML、草稿与发布、二维码、地址轮换、停用与恢复、客户状态校验 | 更多客户端协议与传输 |
| 持久化与运维 | PostgreSQL、会话与审计、版本检查、保数据更新、加密迁移备份、事务恢复与导入前恢复包 | 关系仓储与大规模数据治理 |

设备组面向客户提供一个稳定接入地址，按连接调度；后端故障后客户端需要重连。节点心跳正常不等于真实业务流量已连通。本项目不包含商城、订单、支付、钱包或推广返佣模块。
