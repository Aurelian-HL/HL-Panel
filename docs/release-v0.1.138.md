# HL-panel v0.1.138

修复删除单条客户规则导致同节点全部 Xray 连接断开，以及服务身份删除接口缺失导致 HT 联动清理卡住的问题。

- 日常新增、删除、暂停、恢复、编辑规则按 tag/name 热更 Xray/GOST；无关规则原连接保持。无法安全热更时保留活进程并明确失败，不再自动整进程重启。Mixed 增加两端预检、局部补偿与不确定状态保护。
- 新增管理员专用 `DELETE /api/v1/service-owners/{id}`，要求 revision 与 Idempotency-Key。无引用身份可单独清理，引用冲突返回 409；删除、审计与持久重放同事务提交，不级联规则或订阅，不再次下发节点配置。
- 面板子账号、客户服务身份和 VLESS 身份保持独立；客户 UUID、订阅地址不变。Xray 核心固定 26.7.28，不随本次升级更新。

验证包括全仓 Go 测试、vet、竞态检测、真实 PostgreSQL 提交失败回滚，以及 Ubuntu 24.04 固定引擎专项。专项 80 个 pass 事件、0 fail、0 skip；可靠 UDP chain 正常更新和两种部分失败均通过。真实原 TCP socket 持续收发，PID、CounterEpoch 不变。

面板与节点 Agent 均须升级。升级动作本身存在进程切换窗口；被删除/替换规则自身及共享依赖规则连接可能中断，Mixed 热更不保证跨进程原子性。全局设置变化、缺少控制 API、文件漂移或应用结果不确定时需维护，不以重启兜底。

历史半完成删除不会自动重试；必须核实具体身份与剩余引用后，仅处理未完成步骤。升级前保留上一版程序和配置备份，通过系统更新安装，旧发行包和 tag 保持不变。

验收详情：`docs/rule-live-update-acceptance-20261024.md`、`docs/service-owner-delete-acceptance-20261024.md`。
