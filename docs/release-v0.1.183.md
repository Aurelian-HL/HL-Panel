# v0.1.183 — 删除周期健康验证门槛

原先每条 VLESS 规则在各节点上的协议验证证明仅保留 90 秒。规则数量增加后，复测跟不上会让实际仍能转发的规则重新进入“健康验证过期”，同时影响订阅与网关候选。

## 本轮修复

- 停止面板内周期 VLESS 协议验证任务，删除其对规则就绪、订阅和网关选址的硬性限制。
- 使用节点针对当前配置提交的真实应用回执判断就绪；已有规则不因旧探测证明过期被撤回。
- 修复编辑端口时可能借用旧规则回执的问题。新配置必须收到匹配的应用回执。
- 暂停、额度耗尽、权重 0、退役、身份授权、运行材料和配置应用检查继续生效。
- TCP 业务端口可达性诊断保留；检测失败不能单独证明 IP 被墙。

## 验证范围

新增 600 条规则回归：无协议探测证明时，匹配的部署回执可以立即授权就绪与选址；时间推进一天不会撤回。负向用例覆盖暂停、额度、权重 0、退役、缺失或无效回执、规则版本与端口变更、缺失运行材料。

这项修复消除周期验证等待，不承诺所有节点固定一秒完成下发，也不会修复上游账号被拒绝、端口不监听或网络中断。生产更新及公网验收记录另行保留。

## 更新范围

已运行 v0.1.180 Agent 的 Xray 直连部署只需更新面板，可保留现有 Agent 和 Xray 进程。独立运行的 `connection-gateway` 应同步更新对应程序，才能取消其本地旧证明期限限制。

保留旧数据结构以读取历史状态，不延长或伪造健康证明，不以数据库刷状态替代部署确认。正式包继续由私有源码构建，公开仓库仅提供交付文件与发行包。
