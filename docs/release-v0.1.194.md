# v0.1.194 — 流量积压与规则下发隔离

本版重点处理旧流量重试积压后，删除、新建和更新规则一起等待的问题。面板和节点需要分别升级；本地保护构建，不使用付费 GitHub 构建，Xray / GOST 版本保持不变。

- **积压不再直接占满规则切换所需的计量队列。** 新采样在已编号队列达到水位或容量时进入独立压缩暂存区；配置切换等待本机可靠落盘，不等待历史流量联网补报。
- **保留准确用量。** 压缩保存每次完整事件，保留时间、归属、配置版本、倍率和字节数；不把不同事件合成一个金额，不清空历史队列、不跳过报告。恢复后按原顺序补报并去重。
- **修复两类 Xray 重复计量边界。** 入口计数零增量、或入口统计短暂缺项时，不再切用延迟更新的出口计数重复累计。真正的新进程仍可从出口计量。
- **异常统计不污染基线。** GOST 返回过大的统计数据时拒绝截断结果；Xray 累加溢出时保留旧基线。混合采样失败后重试完整未提交区间。
- **升级与回退保护。** 切换前后检查计量格式，存在新格式压缩数据时阻止换回不兼容旧程序；不能用旧账本快照覆盖新计量。
- **验收能看到真实进度。** 新增只读 `edge-agent --usage-status`，同时显示已编号报告和压缩暂存数量、最近采样时间；只看在线或第一类队列归零不算补报完成。

## 更新方式

第一次从旧 Agent 通过网页升级时，先仅接续维护更新器并保留私有备份，当前任务安全退出，节点与转发不停止；重试使用新更新器完成升级。也可直接使用本版本 `update-node.sh --version v0.1.194`。不能让已运行的旧解释器绕过账本保护。面板按 QWE → AAA1 → 面板4 → HL 顺序，节点逐台备份、升级并验收。

## 边界

压缩暂存、文件容量和磁盘空间仍有上限。历史归属不足、持续网络中断或磁盘满时仍须修复具体原因，本版不伪造成功回执。既有错误累计不会被自动追溯重算。Windows 本地回归、隔离 Linux 与生产逐台验收分别记录；不以编译成功代表物理 iPhone 或全部公网客户端已验证。
