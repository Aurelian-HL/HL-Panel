# v0.1.89

## 设备探针秒级采集

- 节点默认每秒采集并上报主机数据；新装、重装和保留身份升级均显式配置 `heartbeat_interval: "1s"`。
- 探针页面前台每秒读取最新样本。请求耗时不再叠加到节点的每秒调度间隔，失败时仍保留退避，避免并发请求堆积。
- PostgreSQL 面板即时读取最新遥测，业务快照继续节流持久化，避免每秒全量写入。遥测缓存按节点身份隔离并自动过期，不会复活已删除节点。
- 保留节点身份、规则、流量账本和 Xray 26.7.28。升级配置前备份，回滚同时恢复原心跳配置。

## 升级说明

面板服务器运行 `update.sh`，节点服务器运行 `update-node.sh`。两端均升级后才能实现秒级采集和展示；仅升级网页不能缩短旧节点的采样周期。

节点升级会短暂重启托管引擎，应逐台维护。同一采样值可能连续相同，可通过样本时间判断采集是否推进。网络延迟、失败退避和浏览器后台节流可能延长展示间隔。即时遥测缓存当前适用于单实例面板，多副本需要共享遥测存储。

## 验证

覆盖节点固定节拍、配置迁移与回滚、并发遥测、凭据轮换和时钟回退；隔离 PostgreSQL 验证连续样本立即可见、快照版本不逐秒增长、活跃节点不能误删且已删除节点不会被缓存恢复。
