# v0.1.66

减少管理员及节点鉴权中的快照解码开销。缓存仅保留独立的只读身份视图，每次请求仍核验 PostgreSQL 中的快照版本、修订号及行事务标识。其他实例修改密码、撤销会话、轮换节点凭据、删除节点或恢复数据后，后续请求立即读取新状态；数据库不可用时不使用旧缓存放行。

业务查询继续使用各请求独立的数据及历史读取事务，避免并发读取污染状态。会话到期仍按请求时刻判断，不因缓存延长。

补全节点控制指令时间字段的深复制，避免读取结果中的时间指针与仓库状态共享。

修复流量上报、流量查询及流量限制指令接口将临时认证服务故障误报为 401 的问题。这类故障现在返回 HTTP 503 和 `Retry-After: 15`，避免有效管理员会话被误判为失效。无效或已撤销的凭据仍返回 401；初始密码修改要求仍返回 403。

回归覆盖跨实例密码及凭据变更、节点心跳与删除、同修订号恢复、损坏快照、数据库关闭、并发结果隔离，以及五类接口的认证错误分类。

使用面板内保数据更新或正式更新命令升级。更新前保留数据库和配置备份。本版本沿用上一版本的历史存储格式，没有新增数据库格式迁移。
