# v0.1.108

- 将管理员代客户创建转发规则的通用接口并入标准版，保留路径客户校验、权限、额度、幂等重放和审计。普通创建与代创建共用有界异步 VLESS 准备流程，避免把后续配置准备阻塞在保存请求中。
- 规则不可变读视图一次建立导入来源、委托管理权限和出口摘要索引，避免列表、健康续租中逐条扫描身份记录、解析历史创建结果和原生配置；写操作仍在锁内重新验证完整关联。
- 兼容历史导入规则的原生运行材料、显式空 flow、历史流量基线和快照格式。历史流量仅加入累计额度，不计入自然月额度；现有账号、订阅、身份和密钥保持原有数据。
- 保留 v0.1.106/v0.1.107 的流量聚合节流、只读投影和健康续租优化。监听端口扩展按流控能力或节点已经接受的元数据格式下发，避免旧节点仅因元数据格式变化收到无效配置变更。
- 补充委托创建的权限、重复提交、重启恢复、数据库持久化及异步准备测试；补充原生配置、流量基线、读视图隔离和旧版快照升级回归。

标准发行包包含上述通用兼容能力，不包含第三方业务页面、私有迁移工作台或外部后台依赖。节点流控适配保留能力协商，不会因仅更新面板而自动升级节点或 Xray。

更新前使用内置更新器备份。快照格式升级为 22；升级后的业务写入需要支持该格式的程序，不能直接切回不兼容的旧程序，也不能用旧数据库覆盖更新后新增的客户数据。

普通业务写入仍使用快照事务，本版本没有移除所有全量快照写入；短时性能采样也不代表长期运行或客户网络超时问题已经全部消除。
