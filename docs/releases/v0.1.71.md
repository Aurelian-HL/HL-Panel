# v0.1.71

订阅导入包新增 **离线二维码** 文件夹。每条可用线路提供包含完整节点配置的 PNG 和单节点链接，昵称使用当前规则名；小火箭可从相册识别，或扫描另一块屏幕上的图片，导入时无需访问面板下载订阅。原有在线订阅地址、订阅二维码和 Clash / Mihomo YAML 保留。

离线二维码按线路编号，清理不适合 Windows 的文件名字符，避免同名覆盖。二维码按内容密度调整尺寸，超出二维码容量时保留完整链接并提示从剪贴板导入，不会因此阻止整个订阅包下载。未就绪、暂停或无权限的线路仍遵守原有下发限制。

离线配置是下载时的快照，规则名、入口域名和凭据变更后需要重新下载导入；节点连接仍需要网络。离线导入不修改设备时间，也不关闭节点协议的 TLS / Reality 安全验证。
