# v0.1.106

- 规则列表、规则详情和网关调度读取复用不可变的业务投影，减少重复解码完整持久化快照带来的 CPU 和内存分配。
- 规则读取投影只保留节点当前期望配置代数；历史配置继续保存在权威存储，不删除历史数据。
- 持锁评估部署回执时避免逐条规则复制整份节点配置。对外返回的配置与结果仍保持独立副本。
- 每次读取仍核对 PostgreSQL 快照身份，并合并最新流量、协议健康和心跳数据；健康租约过期、额度耗尽、暂停或回执失效时即时重新判断可用状态。数据库不可用时不返回旧缓存作为成功结果。
- 增加并发隔离、租约自然过期、同修订快照替换、数据库故障及真实规则回执评估的回归测试。

本次不更换节点内核，不调整 DNS，不修改数据库结构。更新器继续保留规则、订阅和流量账本，并在更新前备份。

这是读取路径的优化；业务写入仍采用现有快照事务，不能将本次更新视为已消除所有高负载或规则激活等待。带额外业务功能的定制安装需单独合并验证，不能直接覆盖标准发行包。
