# v0.1.107

- 已激活规则的协议健康续租复用不可变规则读视图，不再为每批续租完整解码业务快照，减少 CPU 和临时内存开销，缩短该事务持锁时间。
- 首次激活继续进入完整业务事务，保留激活审计；续租仍与业务修改使用同一数据库行锁，逐条验证规则版本、节点配置、应用回执、成员状态、额度及健康租约。
- 增加暂停、客户禁用、额度耗尽、配置损坏、失效回执、旧版本和过期凭据的拒绝测试，以及并发副本隔离测试。保留 PostgreSQL 的回滚、跨实例读取及并发业务写入回归。

更新器继续在更新前备份并保留规则、订阅和流量账本。本次不更换节点内核、不调整 DNS、不修改数据库结构。

这是健康续租路径的优化，普通业务写入仍使用快照事务；不代表所有页面延迟、规则激活等待或长期运行问题已经消除。带额外业务功能的定制安装需单独合并验证，不能直接覆盖标准发行包。
