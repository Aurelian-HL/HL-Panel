# v0.1.110

- 转发规则名旁增加连接状态：绿色表示有已建立的 TCP 连接，灰色表示无连接或缺少新鲜采样，黄色表示节点配置应用失败或监听缺失。前台每秒读取；采样失效会降为灰色。连接数不等于人数，也不代表出口连通性。
- 节点按监听端口合并 IPv4/IPv6 TCP 连接采样，排除 TIME_WAIT 和仅有出站连接的端口；不上传对端 IP。
- 修复已删除客户的历史用量阻塞后续报数：仅在服务端核验历史配置、应用凭证和归属后继续入账、推进顺序游标，不恢复已删除客户、不下发新限额指令。保留用量账本和节点补报队列。
- 兼容已验证配置中的标准及历史导入 VLESS 统计标签，避免有效用量因标签差异被拒绝。

面板与节点端均需更新才能显示新的连接采样。更新节点代理会重启其管理的转发进程，现有连接可能需要重连；请逐台维护。此版本不调整 Xray/GOST 内核版本。
