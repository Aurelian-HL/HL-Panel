# v0.1.36

订阅管理新增固定 TXT / YAML 地址，支持 1–100 条 SOCKS5 或 VLESS TCP 线路、草稿发布、二维码和 ZIP 导入包。已有 VLESS 凭据在独立标签页继续管理；设备组仍只提供一个稳定端点。

- 保存草稿不改变已发布内容；发布更新保持地址不变。
- 更换地址使旧地址失效；订阅可停用并恢复。
- 客户停用、到期或额度耗尽时停止下发。原生凭据每次读取当前账号和线路健康状态。
- 多客户引用管理员同一 VLESS 凭据会共享底层线路账号。订阅停用不会禁止已缓存配置连接，需要另外管理底层账号。
- 手工链接支持 SOCKS5、VLESS TCP（Reality / TLS / 无 TLS）；不支持 WS / gRPC。面板不会主动访问手工链接。
- 订阅列表与审计不返回访问凭据；订阅公开路由关闭 Nginx 访问日志，服务日志隐藏令牌。

请使用仓库根目录的一键 `update.sh` 更新。更新器会备份数据库和配置，仅为受管 Nginx 配置补充订阅路由，保留域名、证书和自定义路由。失败自动恢复，终端提供备份路径与回滚命令。旧版本回滚必须同时恢复对应数据库快照，不能只切换程序。

验证包含 Go 测试与 vet、Vue 类型检查及测试、前端构建；正式发布还通过隔离 PostgreSQL 持久化、全新安装、节点安装、更新回滚和真实 Xray / GOST 转发检查。公开订阅内容格式支持不等于所有第三方客户端均已实际验收。
