# v0.1.55

- 修复面板和节点服务限制导致的网卡地址采集失败：允许采集器使用 AF_NETLINK，保持服务无网络管理能力。
- 保数据更新自动修复旧面板的受管指标配置，保留原配置备份和回退能力；自定义配置不会被覆盖。
- 首页区分 IP 地址未配置、采集失败与尚未采集。未配置公网 IPv6 的服务器显示“未配置”。
- 增加 IPv4、IPv6 单栈和采集权限失败测试，并在真实 Linux 新装、节点安装和保数据更新验收中检查地址采集状态。

已安装的旧节点需升级节点服务配置；仅更新节点程序不会自动修改原服务的地址族限制。节点的观察来源 IP 仍可用于探针展示，面板 IPv4 不会借用节点地址。
