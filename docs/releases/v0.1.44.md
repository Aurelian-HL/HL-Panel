# v0.1.44

首页的日志和版本入口改为白底弹窗，移除独立日志卡片。

- 日志读取面板自身的真实运行记录和管理员操作请求，支持刷新、条数、搜索、级别筛选与 UTF-8 下载。管理员认证保护，排除日志属性和请求正文，遮掩常见凭据；受管日志原子保存且限制为 2000 条 / 2 MiB。
- 版本列表读取固定项目仓库的正式 Release，按语义版本排序，标记当前版本并禁止选择旧版更新。选择新版后复制指定版本的保数据更新命令，在面板机终端执行。网络失败明确提示；查询沿用原缓存与更新提醒策略。
- 首页仍展示面板机的系统状态，节点合计指标保持原统计范围。

已有实例使用根目录 update.sh 保留账号、规则、数据库、域名与证书更新；升级前自动备份。日志从升级后开始收集，旧日志不自动导入。本次没有改变停止、重启的服务控制器配置。

验证包括 Go 日志容量、隐私、重启持久化与 API 权限测试，Release 过滤/排序测试，Vue 弹窗操作、下载、失败重试和首页入口测试，以及正式发布工作流的安装与保数据更新检查。
