# v0.1.46

缩短转发规则保存后等待激活的时间，激活状态仍以真实引擎和协议检测结果为准。

- VLESS Reality 的首份可执行配置同时包含客户身份和独立探测身份，避免后台补探测身份后再次下发、重启引擎。
- 新节点端使用经过认证的配置长轮询：配置事务提交后立即通知节点，无变化时保持短时等待。旧面板与旧节点接口继续兼容。
- 节点完成引擎验证并持久保存回执后立即触发协议检测；定期扫描继续作为恢复和通知丢失的兜底。
- 同一规则最多并行检测四个候选节点，任一合格节点通过真实协议检测即可激活，避免慢节点挡住已就绪节点。暂停或不可用规则不参与检测。
- 激活写入校验规则修订号，防止旧配置检测结果误激活新配置；重复成功检测不重复记录激活审计。

已有面板运行 `update.sh --version v0.1.46` 保数据更新；节点运行 `update-node.sh --version v0.1.46`，保留节点身份、分组、凭据和现有配置。更新前自动备份并生成回滚脚本。节点也升级后才能使用立即通知能力，旧节点继续按原周期拉取。

验证涵盖配置首次下发、事务提交通知、失败事务无通知、等待期间凭据失效、旧接口兼容、并发检查，以及两轮真实 Xray 的规则保存、节点应用、协议激活和客户传输。所有自动化协议测试使用隔离回环资源。
