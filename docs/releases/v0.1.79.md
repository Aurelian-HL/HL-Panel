# v0.1.79 — 规则流量性能优化与升级恢复修复

本次正式发布包含 v0.1.78 候选版的规则流量持久汇总与增量写入优化。v0.1.78 未通过保数据升级检查，未正式发布。

- 累计和完整 UTC 月额度改查持久汇总，避免重复扫描历史账本；汇总与账本写入、去重、回滚保持同一事务。
- 普通规则用量增长只更新独立计数，减少整份业务快照的编码、写入和缓存失效。跨额度、月清、业务编辑仍保留原有事务、暂停和审计行为。
- 修复升级失败后新增派生表、触发器和函数残留，导致再次升级被判定为未受管数据库对象的问题。仅移除旧备份中不存在的本项目对象；旧备份已有的汇总和用量记录继续恢复保留。
- 强化真实升级回归：必须启动新版本后才触发失败，并确认数据库恢复到原有结构，再执行二次升级。

仅更新面板端，无需重装节点。首次升级会在事务内回填历史用量。程序切换前自动备份数据库、配置和程序并提供回滚脚本。旧版本不识别独立用量记录，不能只替换二进制降级；恢复业务后降级必须先保存当前完整数据库和迁移包，确认恢复点，避免覆盖升级后新增业务。

高频流量已从全量快照中拆出，其他业务状态仍使用集中快照。线上 CPU 效果需要同方法采样，短时结果不代表长期峰值。
