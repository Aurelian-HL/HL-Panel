# v0.1.111

- 修正 TCP 探针连接数口径：只统计 `ESTABLISHED`，排除 LISTEN、SYN、TIME_WAIT 和其他生命周期状态，避免规则在线状态与 NY 探针出现数量偏差。
- 保留按监听端口合并 IPv4/IPv6 的统计；规则状态继续由新鲜采样实时派生，前台每秒刷新，采样过期或节点异常时显示离线/错误状态。
- 保留规则流量的顺序入账与实时读取：新建规则在没有实际流量时显示 `0`，不会伪造用量或跳过账本序号。

面板和节点端均需更新到同一正式版本，才能使用一致的探针连接数口径。此版本不调整 Xray/GOST 内核版本，也不清理历史用量账本。CPU 优化仍需继续治理规则配置校验和数据库聚合负载。
