# v0.1.68

修复同组新增规则后，已有规则重新验证时可能被未成功节点的探测队列拖慢的问题。配置切换后优先复验近期成功的节点，每条尚未恢复的规则先安排一个候选，减少大型设备组的重复等待；已恢复规则继续优先续验当前配置的健康节点。

规则页面区分“配置同步中”“验证中”“健康验证过期”和“暂无可用节点”，方便判断等待原因。阶段说明只用于当前状态展示，不写入持久配置，不改变规则、账号、订阅或流量额度。

新增规则仍会更新节点的完整配置，配置切换及真实协议验证期间可能出现短暂等待。旧配置的健康结果只作为探测顺序参考，不能授权新配置；不会通过延长健康有效期或心跳替代真实 VLESS 验证。

回归覆盖同组新增规则引起的完整配置变化、新部署回执与新协议证明恢复、旧证明拒绝、地址变更、过期证明调度、连续刷新及编辑后的快照可读性。没有新增数据库格式迁移，可通过面板保数据更新升级，更新器会保留数据库和配置备份。
