# v0.1.109

- 修复旧节点拒绝 `usage.listen_port` 后持续收到相同不兼容元数据的问题。仅从节点已成功应用的配置继承历史元数据，不再把尚未应用的期望配置视为已接受格式。
- 编译器修订号升级为 3，由节点心跳执行一次兼容协调。配置内容未变化的节点不会增加代次；失败节点保留历史配置，仅移除未协商的监听端口元数据，不修改引擎配置、协议身份或密钥。
- 增加从未应用、旧配置已应用、失败回退、重复心跳及服务重启的回归测试，并保留成功应用过的旧元数据格式。

包含 v0.1.108 的通用代客户创建规则接口、异步配置准备和列表索引优化。标准版不包含已迁出的第三方业务页面，也不依赖外部运营后台。

本次只更新面板，不自动升级节点程序或 Xray。快照格式仍为 22；请使用内置更新器备份，不要用升级前数据库覆盖升级后新增数据。普通业务写入仍有全量快照成本，本次修复不代表长期运行及所有网络超时问题均已消除。
