# v0.1.73

修复节点在已应用配置后引擎意外退出、没有新配置下发时无法自行恢复的问题。Agent 增加独立恢复循环，使用本地最近验证成功的配置重新启动受管引擎，控制面不可用时也可执行；终态回执保存在本地，恢复联网后补报。包含 v0.1.72 的 Xray 退出通知广播修复。

主动停止现在持久化保存，Agent 重启或新 generation 不会自行解除停止；点击重启后恢复最近配置并继续配置同步。停止、重启、配置应用与自动恢复采用同一个生命周期锁。重启前将最后可读的流量计数保存到本地账本。空配置不进入周期性恢复，存活进程不会被例行检查重启。

发布流水线增加真实 Xray 退出、控制面离线、主动停止/重启和真实 loopback 转发回归。新增 [节点稳定性维护](../node-maintenance.md)，说明诊断、滚动升级、保身份/账本、回滚与后续维护事项。

修复自定义 `xray_stats_api_address` 被编译器忽略的问题。准备、验证、激活与回滚统一使用配置中的本地监听地址，默认仍为 `127.0.0.1:10085`；拒绝公网地址和非法端口。回归包含真实转发后的统计 API 查询。

面板升级不会自动升级节点。已有节点需执行保身份更新，逐台切换并核对真实转发；切换会短暂断开该节点已有连接。该修复解决已确认的进程生命周期缺陷，不能保证所有间歇超时均由此引起，也不提供自动 DNS 故障摘除。
