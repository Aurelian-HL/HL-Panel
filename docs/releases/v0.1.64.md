# v0.1.64

修复节点配置历史不断扩大控制快照、增加页面查询和配置写入负担的问题。旧配置代、部署回执和尝试记录一起保存至 PostgreSQL 历史表，热快照保留每个节点当前期望及已应用的配置。启动时自动执行事务迁移；失败时不提交任何数据变更。历史记录仍可用于迟到流量核验、回执重试和完整迁移备份。

订阅查询遇到数据库不可用或超时，返回可重试的 HTTP 503 和 `Retry-After: 15`，不再误报为订阅不存在或客户停用。多条订阅线路中发生基础设施错误时，终止本次生成，避免导出不完整的订阅。

移除设备组中尚未实现的“清空流量”按钮。

完整控制数据备份的上限提高至 64 MiB；热快照仍限制为 16 MiB。加密备份文件上限仍为 64 MiB，展开后所有内容合计仍为 128 MiB。原有较大流量账本备份仍可导入。导入新版本备份前，请先将目标面板更新至本版本或更高版本。

请使用正式保数据更新器升级。回退旧版本时，必须同时恢复升级前的数据库和配置备份；只替换旧程序无法读取已拆分的历史。升级后有新增业务数据时，应先另行保存，不要直接覆盖数据库。

回归验证覆盖历史自动归档、迟到回执及流量核验、故障时事务回滚、重启、完整迁移恢复、超过 16 MiB 的历史备份，以及较大旧版账本备份的兼容性。
