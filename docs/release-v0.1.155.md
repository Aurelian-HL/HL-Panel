# HL Panel v0.1.155

本次在 v0.1.154 已发布的持久化修复上增加侧边栏商店及独立授权服务的一次性兑换码协议，保留既有规则、订阅、节点身份和授权。

- 商店展示月、季、半年、年、永久五种授权方案，可配置外部发卡商城购买链接。未配置的价格和购买入口明确显示尚未开放，不生成虚构商品价格。
- 增加一次性库存码、签名兑换收据和结果恢复：兑换码不写入浏览器存储或日志；收到并持久保存签名收据后才提交激活；恢复结果不会重复续期。
- 验证目录签名、请求随机数、时效及购买链接，拒绝跨域名、跨实例、重放和重复使用。输入错误不回显兑换码。
- 兼容尚未提供商店协议的授权服务：目录接口明确返回 404/405/501 时显示“商店尚未开通”，禁用购买和新兑换；保留当前授权。其他服务错误和签名校验错误继续作为错误处理。

## 部署边界

此次只升级 HL 面板。面板服务切换时，登录、管理 API、订阅读取和统计刷新可能短暂不可用；已运行的节点 Agent、Xray、GOST 不在升级范围，现有转发使用节点已有配置。

HT 生产授权服务和外部发卡商城尚未在本次部署中启用，因此真实购买、发卡和兑换不算交付。发行包包含其独立实现，但面板升级不会自动部署授权服务或节点。

## 验证

保留 v0.1.154 持久化预算修复。新增目录兼容回归、签名与兑换测试、三个视口的商店浏览器检查；正式发布须通过同一提交的完整 Linux CI、安装和升级矩阵，生产切换后比对节点进程、监听及连接身份。
