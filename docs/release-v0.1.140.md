# HL-panel v0.1.140

日常配置变更的异常补偿现在只处理实际尝试过的对象，减少对其他客户连接的影响；个人中心重新排版，设备探针增加仅本地显示的备注。

## 转发连续性

- 受管 VLESS 与导入配置的叶子出口使用内容版本标签，先创建出口、切换路由，再清理旧出口；补偿时先恢复旧出口与路由，再清理候选。
- Xray 与 GOST 记录实际请求进度，早期失败不再补偿尚未操作的规则；路由未变化时不重复替换路由。
- 缺少可信回滚记录但仍有存活核心时拒绝激活，避免空回滚误停仍在工作的引擎。
- 严格验证 GOST 变更确认与对象不存在的响应，状态不确定时保留存活进程并停止进一步变更。
- 保留计量归属、客户 UUID、监听端口及 Reality 身份；不升级已锁定的 Xray 核心。

## 界面

- 个人中心改成账号概览、域名授权、账号安全三个等宽纵向区域，适配窄桌面与手机。
- 设备探针 IP 旁增加备注编辑入口；保存后以备注代替列表 IP，清空恢复。真实地址、连接、规则、订阅不变。
- 备注保存在当前站点的浏览器本地存储，刷新与切组后保留，同源标签页同步；其他浏览器和设备不共享。

## 验证与升级边界

本地整仓库 Go 回归、相关包竞态检查、静态检查、前端测试及生产构建纳入发布检查。正式发行仍由 GitHub Actions 的 Linux 真实引擎、全新安装、保留数据升级、回滚与网页更新检查全部通过后生成。

本次不承诺所有操作绝对无中断：修改被操作规则的监听、删除该规则、节点升级和主动停机仍会影响对应连接；GOST 服务替换与 Xray 路由更新也有各自边界。节点 Agent 升级可能中断该台连接，需逐台执行并检查。面板升级应保留现有身份、规则和订阅，完成后以实际运行版本和接口结果验收。

详细记录见 `docs/xray-continuity-audit-20261024.md`、`docs/profile-layout-20261024.md`、`docs/probe-remarks-20261024.md`；这些文件中的“未发布”描述记录的是开发阶段状态，最终发布与生产验收另行记录。
