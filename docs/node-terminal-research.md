# 节点维护入口

探针与节点清单已接入固定用途的“更新”弹窗，详细行为见[节点一键更新](node-one-click-update-design-20261019.md)。代码接入不等于正式发布和生产验收。

新节点从“节点令牌”安装自动接入；旧节点在自身 root 终端执行一次弹窗的保身份命令，此后可以在面板选择正式版更新或同版本修复。面板不会自动批量升级所有节点。

任务持久化、全局串行、幂等、权限隔离、官方包校验及恢复已纳入实现。Agent 通过 HTTPS 主动领取，本机 root 服务执行，无需面板保存 root 密码或开放维护端口。程序切换会断开连接，身份和订阅保留。

完整交互式 SSH 终端本轮未实现。仓库禁止任意远程 shell，不能用通用命令通道代替受控更新。未来如单独授权终端，应另行定义短时会话、管理员验证、主机密钥、凭据、权限及审计边界。
