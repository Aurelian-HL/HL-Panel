# 节点终端与一键更新研究

## 当前能力与边界

探针行操作列目前有权重、监测详情和条件删除。心跳在线仅代表 Agent 最近上报，不证明新配置已应用或全部规则可用；应同时查看节点清单的期望/已应用代数、应用结果和协议健康。

现有节点控制接口只允许既定的停止、重启等操作，没有 SSH 会话或升级任务协议。面板更新不会自动升级节点，也不能通过已有心跳凭据直接登录服务器。旧节点必须先通过原有 SSH 命令完成一次保身份升级，才能支持未来新增的任务协议。

## 建议的操作入口

在眼睛按钮右侧增加“维护”入口，分别展示诊断结果、节点版本和更新任务。优先实现受控的一键更新；完整交互式终端独立设计，不以任意 shell 字符串实现更新。

一键更新任务应包含：管理员授权、审计、幂等键、目标节点与不可变正式版本、官方资源清单及 SHA256 校验、到期时间、执行租约和重启后恢复的任务状态。Agent 主动获取任务，无需新增公网 SSH 端口，也不由面板保存 root 密码。禁止任意 URL、路径、命令和用户输入参数拼接。

更新器必须复用已有保身份升级流程：下载验证完成后再切换；备份配置、身份和流量账本；失败自动回滚；由独立受管进程执行，避免 Agent 停止后任务丢失。状态需区分排队、下载、校验、备份、切换、回滚、失败和成功，成功需新版本心跳及配置回执验证。节点离线不得显示成功；按节点串行操作。升级切换会断开该节点现有连接，订阅地址和凭据应保持不变。

## 完整 WebSSH

技术上可行，但当前仓库禁止任意远程 shell。不能把“终端”按钮接到通用 root 命令通道后直接发布。若后续决定开放，应单独明确产品权限边界，实现短时单次会话、重新验证管理员身份、SSH 主机指纹绑定、凭据安全存储、WebSocket 认证与 Origin 检查、空闲/总时限、会话并发限制、服务器端授权和审计。终端输出可能包含秘密，审计默认记录会话元数据，命令/输出录制需独立权限和脱敏设计。
