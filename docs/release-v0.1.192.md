# v0.1.192 — 批量创建、链接导出与订阅恢复

本版重点处理规则较多时的删除失败、订阅误报失效和重复请求覆盖。使用本地保护构建并直接上传发行包，不使用付费 GitHub 构建；Xray / GOST 固定版本不变。

- **SK5 一行一个，批量创建。** 粘贴 `IP:端口:账号:密码`，昵称默认使用上游 IP；入口设备组与规则分组统一选择。每批最多 500 条，入口端口在设备组允许范围内随机分配，避开已占用端口及共享机器上的冲突。整批原子保存，失败不留下半批规则，重试保留已分配的端口与账号。
- **节点链接、订阅链接批量导出。** 选择规则后导出已选项，未选择时导出当前筛选结果的全部分页。每行一条，可复制或下载 TXT；仍保留配置 JSON 导出。订阅地址已有则复用、没有才创建；不自动恢复已撤销订阅，不轮换账号或旧地址，失败项单独说明。每次最多处理 128 条并顺序分批，避免大量并发请求阻塞控制接口。
- **删除不再反复排队。** 并发写入导致预计算结果过期时，保留已取得的写入机会，基于最新数据重算后提交，避免反复回到队尾。保留数据库事务、审计、计量合并和幂等约束；提交结果不明时不会自动重复删除。
- **错误显示在当前弹窗。** 排队超时会明确提示本次未提交；删除失败原因直接显示在弹窗内，手动重试沿用原请求标识，成功后才移除服务端确认删除的规则。
- **临时读取故障不再误报订阅不存在。** 导入订阅读取失败时返回可重试的 503、Retry-After 和禁止缓存响应。服务恢复后继续使用原订阅 URL，无需重建端口、账号或订阅。
- **复用订阅也记录幂等结果。** 同一请求重试不会覆盖后来编辑；相同请求标识更换内容会拒绝，重启后仍有效，审计记录对应实际订阅版本。
- **补齐客户端配置核对接口。** 支持有界批量配置指纹，供授权的订阅发布端识别客户端可见字段变化。接口本身不代表外部发布端已部署联调。
- **修复握手检测轮转。** Agent 中某组检测报错或取消后仍遵守重试间隔，让其他组获得检测机会；中断后重新累计连续优势，避免过早切换。该项需要更新 Agent，仅更新面板不会生效。

继续保留 v0.1.191 的自动 SNI 候选收紧和原客户端身份。内部握手目标切换与客户端 SNI 更新是不同环节，客户原 SNI 在其网络上不可用时，仍需协调更新原订阅并由客户端刷新。

面板升级会短暂中断管理请求。生产范围、原订阅与转发抽测、备份和回滚以逐台部署记录为准；本地回归不等于所有用户、所有网络均已验收。
