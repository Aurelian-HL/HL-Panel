# HL-panel v0.1.139

修复删除单条客户规则导致同节点全部 Xray 连接断开，以及服务身份删除接口缺失导致 HT 联动清理卡住的问题。

- 日常规则变更按 tag/name 热更 Xray/GOST；无法安全热更则保留活进程并报失败，不再通过整进程重启兜底。Mixed 增加两端预检、局部补偿和不确定状态保护。
- 新增管理员专用 `DELETE /api/v1/service-owners/{id}`，要求 revision 与 Idempotency-Key。无引用身份单独删除；引用冲突返回 409，不级联规则或订阅，不触发节点下发。删除、审计、幂等重放同事务提交。
- 面板子账号、服务身份和 VLESS 身份独立；客户 UUID、订阅地址保持不变，Xray 核心固定 26.7.28。
- 安装验收的手写 Xray 夹具补齐明确出口路由，符合面板生成配置与安全热更要求。v0.1.138 被该安装关卡拦截，未发布正式包；保留原 tag，不覆盖发布。

已有验证：全仓 Go 测试、vet、竞态检测、真实 PostgreSQL 提交失败回滚；Ubuntu 24.04 固定引擎专项 80 pass、0 fail、0 skip，包含真实原 socket 保持及可靠 UDP 部分失败补偿。v0.1.139 正式发行仍须通过完整 CI 和安装验收，不能以此前专项代替。

面板和节点 Agent 均须升级。正式升级本身有进程切换窗口；被删除或替换规则自身及共享依赖可能中断，Mixed 不保证跨进程原子性。历史半完成删除不会自动重试。升级前保留上一版备份，通过系统更新安装。

验收详情：`docs/rule-live-update-acceptance-20261024.md`、`docs/service-owner-delete-acceptance-20261024.md`。
