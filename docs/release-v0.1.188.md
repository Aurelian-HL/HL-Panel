# v0.1.188 — 计量、下发与更新稳定性修复

本版集中修复此前排查出的计量确认、配置回执、节点维护和登录问题，并完善规则列表。已有规则、订阅身份和累计用量保持原有语义；不升级 Xray / GOST。

## 主要修复

- **流量确认与展示解耦。** 账本已提交的报告不会再因展示投影失败而无限重报；真正未入账的报告仍不确认。慢规则按轮次继续刷新，避免后续规则长期没有用量。
- **大积压处理优化。** 重用经过内容校验的不可变计量段，减少重复解码和序列化，保留确认、去重与数据损坏检查。
- **下发与回执隔离。** 批量恢复保留单节点截止时间；单条异常回执不再拖累其他有效回执。节点控制保留防重放记录，重复完成回执不反复追加审计。
- **更新任务恢复。** 更新器在超时、子进程持有输出管道或执行中断时正确收尾，保留恢复目录；未领取的过期任务不再长期挡住其他节点。
- **网关按路由隔离。** 删除路由返回明确空成员；单池坏数据和监听冲突不再中断其他池。发行包包含独立网关程序，但安装包不会自动接管旧路径的网关服务。
- **登录及运维日志。** 旧密码并发登录不能绕过密码修改；数据库故障不再伪装为客户未登录。旧请求不清除新会话，运维日志避免高频重写整份历史。

## 界面调整

- 规则列表支持流量最多、最少和名称、入口、出口排序，先排序再分页。
- 修复旧接口中隐藏页流量增长后排名不更新，以及原生出口、完整 IPv6 地址搜不到的问题。
- 行内只展示在线状态，移除协议副标题、连接采样说明及无效点击；删除个人中心多余授权说明。
- 调整概览排行卡片，使尺寸、背景与同排卡片一致。

## 发布与升级

本版按既有授权从私有源码的固定提交在本地构建并上传，公开仓库只提供安装文件和发行包。完整 Linux 安装矩阵与真实客户端验收不以本地单元测试替代；详细结果记录在对应发布验收报告中。

按 QWE、AAA1、HL 顺序，先面板后所属节点，逐台备份、升级、核对原规则转发和计量进度；HL 最后。发现失败先处理当台，不清空计量、不重建客户规则、不修改 DNS 或上游服务。独立网关的实际运行路径需另行核对，不能以面板版本代替网关版本。

Agent 维护会短暂中断被操作节点的连接，客户端需要重连。原有连接不会自动迁移，供应商网络或上游故障仍需单独排查。
