# v0.1.189 — 网关同步隔离与 IPv4 探测修复

本版集中修复旧网关升级遗漏和多规则同步相互拖累的问题；保留现有规则、端口、订阅身份及计量数据，不更换 Xray / GOST 版本。

## 主要修复

- **多规则同步独立等待。** 共享成员刷新不再持有锁等待网络；一条规则取消等待不会拖累其他规则，网络请求仍保留 5 秒上限，失败时沿用各自最后有效配置。
- **旧网关纳入节点更新。** 新更新器同时更新已安装的标准旧网关服务，核对实际进程程序摘要；失败可恢复旧程序，停用的网关保持停用，配置与 NAT 保留原状。旧更新器首次升级需单独运行本包固定用途的旧网关更新步骤。
- **TCP 探测只检查 IPv4。** 自动和手动检测均只接受节点实际采集的公网 IPv4；多 IP 逐个检测，IPv6 仍可展示和用于注册、转发，但不再显示无意义的“不可测”结果。

## 发布与验收

私有源码固定提交、本地构建、上传公开发行包，不使用付费 GitHub 构建。逐台备份并更新，顺序为 QWE、AAA1、第四面板、HL；验证实际版本、配置回执、原端口转发、持续采样及计量积压。无法获取的凭据或未通过的测试单独列入部署报告，不能以在线状态代替验收。

维护 Agent 和旧网关可能使该节点连接短暂重连。上游 SOCKS5 认证失败或拒绝连接需要单独修复，不应通过重建客户端口掩盖。
