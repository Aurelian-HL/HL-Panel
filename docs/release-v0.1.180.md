# v0.1.180 更新说明

本版围绕多 IP、规则恢复、用量排行和节点维护收尾。面板和 Agent 需一起更新，Xray / GOST 固定版本保持不变。

v0.1.175～v0.1.179 候选未公开发布、未升级生产；本版进一步修复手动关闭 TC 时遗漏连接清理权限的问题，保留管理员原有的 TC 设置。

## 多 IP 与探针

- Agent 上报实际公网 IPv4 / IPv6 地址集合，兼容旧版单地址字段。
- 探针展示同一 VPS 的多个地址，允许指定地址执行 TCP 业务端口检测；后台轮转检测全部当前地址。
- IP 变化时撤掉旧地址的检测结论；设备备注保存在面板，其他电脑登录仍可查看。
- 操作统一为“设权 / 查看 / 更新”，权重弹窗增加快捷档位，适配桌面和手机。

探测结果属于该地址、该端口和该时间。Ping 或 SSH 成功不能代表业务端口正常，一次 TCP 失败也不能独立证明被墙。此功能不修改 DNS 或自动停用节点。

## 规则删除与恢复

- 受支持的导入规则与客户委托规则，归档加密后与删除在同一数据库事务中提交。
- 修复恢复时误改其他规则 SOCKS5 用户名的问题，保持原有客户累计用量及账号边界。
- 兼容既有恢复接口；旧文件缺失或损坏不阻塞数据库删除归档的查询与恢复。指定不可用旧归档恢复时明确返回暂不可用，避免误报接口不存在。
- 恢复密钥缺失时明确拒绝相关操作，不阻塞登录或已有转发。
- 更新器把恢复密钥纳入匹配的数据库回滚点，支持默认及自定义密钥位置。

归档不能代替完整数据库备份，也不是所有管理员自建资源的任意恢复。迁移与回滚须保留对应的数据库和密钥。

## 24 小时用量排行

- 概览增加“VPS 最猛 TOP 3”，统计当前设备组成员的主机上行与下行总量。
- 同一节点加入多个组、拥有多个 IP 均只计一次。
- 约 5 分钟记录一次，保留约 26 小时；有界异步写入避免拖慢心跳，旧采样自动清理。
- 首次启用从首条基线累积，不虚构之前 24 小时数据；网卡用量与客户计费分开。

## 权重 0 与持久化修复

- 从正权重改为 0 时撤回该节点对应设备组的监听，热应用成功后清理被撤回端口的 TCP 连接；其他组和其他端口保留。
- 恢复正权重后重新生成监听，正权重之间调整不触发整核重启。
- 清理后检查连接是否真正消失；工具或权限不足时明确失败，保留/恢复最后有效配置。
- 补齐节点所需的 `ss` / iproute2；修复 HTTP 调用方断开导致已受理应用回执取消持久化的问题。

权重修改需指令到达并成功应用，断开的连接需要客户端重连，不能无损搬迁 TCP 会话。仅一台可用节点时，没有备用机器可以承接。

- 升级失败回退旧版时，按原备份清理旧版不存在的归档与排行表，避免下次升级读取遗留结构；原备份已有的表保持。

## 发布与升级

本地 Go、数据库、前端及三尺寸浏览器检查通过后，还需通过正式流水线中的 Linux 实际引擎、非 root systemd 能力、安装、升级和回滚检查，才发布程序包。

先更新面板，再逐台更新 Agent 并检查心跳、配置回执及既有业务转发。面板切换短暂影响管理与订阅下载，节点更新可能引发该节点连接重连；不同时更新整组。

本版延续 v0.1.174 的配置复用、gzip 和批量回执提速。下发速度受机器、规则规模和链路影响，仍不承诺所有节点固定一秒内可用。
